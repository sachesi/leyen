# Keyboard shortcuts

Ctrl+? shows this list inside the application.

| Keys | |
|---|---|
| Ctrl+F, or typing | Search the library |
| Enter | Launch or stop the game under the keyboard, open the group |
| Escape, Alt+← | Back from a group to the library |
| Ctrl+, | Preferences |
| Ctrl+? | Keyboard shortcuts |
| Ctrl+W | Close the window |
| Ctrl+Q | Quit |
| F10 | Main menu |

In the dependency manager typing searches the components straight away.
